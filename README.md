# Пустошь — Post-Apocalyptic RPG

Изометрическая пост-апокалиптическая RPG в духе **Fallout 1-2** и **ATOM RPG**, написанная на **TypeScript + Phaser 3** и запускающаяся прямо в браузере.

## Возможности

- 🎲 Система характеристик **S.P.E.C.I.A.L.** (Сила, Восприятие, Выносливость, Харизма, Интеллект, Ловкость, Удача)
- 🛠 Шесть навыков: Лёгкое оружие, Ближний бой, Медицина, Взлом, Речь, Скрытность
- ⚔️ Пошаговая боевая система с очками действия (AP)
- 💬 Ветвящиеся диалоги с проверками характеристик и навыков
- 🗺 Четыре локации: Деревня Ольховка, Пустошь, Бар «Три собаки», Лагерь рейдеров
- 📜 Основной квест + побочные задания
- 🎒 Инвентарь, оружие (ближнее/дальнее), броня, расходники, патроны
- 🎯 Система критических ударов, зависящая от Удачи
- 💾 Сохранение/загрузка через `localStorage`
- 🌐 Полностью на русском языке

## Запуск

```bash
npm install
npm run dev
```

Затем откройте http://localhost:5173/ в браузере.

## Сборка

```bash
npm run build
```

Собранные файлы окажутся в `dist/`.

## Управление

**Исследование:**
- `WASD` / стрелки — передвижение
- `E` / `пробел` — взаимодействовать (говорить, подобрать, перейти)
- `I` — инвентарь
- `J` — журнал квестов
- `C` — характеристики и навыки
- `F5` — сохранить
- `F9` — загрузить
- `Esc` — меню паузы

**Бой:**
- `1` — атаковать ближайшего врага в радиусе оружия
- `2` — закончить ход
- `WASD` / стрелки — шаг на клетку (1 AP)

## Технологии

- [Phaser 3](https://phaser.io/) — игровой движок
- [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vite.dev/) — сборка и dev-сервер

## Структура

```
src/
  main.ts               — точка входа, конфиг Phaser
  types/                — общие TypeScript-типы
  data/                 — контент игры (предметы, враги, локации, диалоги, квесты)
  systems/              — системы (характеристики, бой, сохранение, мир, состояние)
  scenes/               — сцены Phaser (меню, мир, диалоги, инвентарь и т.д.)
  ui/                   — UI-хелперы
```
